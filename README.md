# 🚔 QBCore Utility Pack

A custom QBCore resource developed for roleplay servers, providing police management tools, black money conversion, and welcome reward systems.

---

## ✨ Features

### 👮 Police Illegal Dealer
- Grade restricted police access
- Password protected dealer
- Sell confiscated illegal items
- Money goes directly to police management account

### 💰 Black Money Conversion
- Hacking minigame required
- Dynamic conversion rates
- Police count affects payout
- Bank deposit after successful conversion

### 🎁 Welcome Rewards
- Random starter vehicle
- Starter food package
- Vehicle ownership registration
- Automatic key assignment

### 🚗 Vehicle System
- Unique license plate generation
- Database integration
- Fuel support
- Vehicle property saving

### 📢 Discord Integration
- Automatic restart notifications
- Embedded webhook messages

---

## 🛠 Dependencies

- qb-core
- qb-input
- qb-management
- LegacyFuel
- qb-vehiclekeys
- qb-mechanicjob
- mhacking
- oxmysql

---

## ⚙ Configuration

Configure everything inside `config.lua`.

- Police item prices
- Welcome rewards
- Black money conversion rates
- Password
- Vehicle rewards
